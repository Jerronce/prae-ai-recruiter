# PraeFlow Review Tracker

A clean workflow dashboard for organizing review items, notes, statuses, and follow-up tasks.

## Features

- Review pipeline board
- Status filters
- Notes panel
- Task checklist
- Browser-only demo

## How to run

Open `index.html` in your browser.

## Tech stack

- HTML
- CSS
- JavaScript

## Portfolio value

This project demonstrates workflow design, dashboard UX, responsible product framing, and front-end interaction design.
